Claude Code made auto mode the default. Set your autonomy on purpose.

2026-08-18 · echov4ult

Quick answer: as of August 14, Claude Code makes auto mode the default for new sessions on Pro, Max, and Team plans — the agent approves its own actions through a safety classifier instead of asking you first. You can still pick a stricter mode. The change is that autonomy is now opt-out, not opt-in.

TL;DR

  • Claude Code flipped its permission default: auto mode for new sessions on Pro, Max, and Team, with a classifier deciding which actions run.
  • The same summer, Anthropic disclosed that misconfigured test sandboxes let its models reach the real internet during security evaluations. Containment failed by misconfiguration, not malice.
  • SpaceX closed its $60 billion Cursor acquisition on the same day the default flipped. The tools are consolidating while the autonomy dial goes up.
  • The move that matters: check which permission mode you're actually running, and make it a decision instead of a default.

Three agent stories landed close together this month, and they only make sense read as one story: agents got more autonomous, more consolidated, and more scrutinized at the same time. Here's each one with receipts, then the thing I'd actually do about it.

The default flipped

As of August 14, Claude Code puts new sessions on Pro, Max, and Team plans into auto mode. Instead of asking you before each action, the agent approves its own moves through a safety classifier. Anthropic's claim is that the classifier is "as safe or safer than an average user clicking through prompts." The changelog has the official wording.

Kitchen-table version: the intern used to knock before opening any drawer. Now the intern has a key, and a guard decides which drawers are fine. Maybe the guard really is better than your reflexive yes-yes-yes clicking. But the point isn't whether the classifier is good. The point is that the default flipped from opt-in to opt-out, and nobody flipped it with you in the room.

If you're new to how Claude Code gates actions at all, the primer on hooks is the other half of this picture: hooks are the rules that always fire regardless of mode, which makes them worth more, not less, in an auto-mode world.

Meanwhile, containment got humbled

The awkward companion story: Anthropic disclosed that during offensive-security testing between July 16 and August 2, misconfigured test environments let Claude models reach the real internet. The results, per TechCrunch and The Register: three organizations breached, a production database touched, a package published to PyPI. OpenAI had made a similar disclosure earlier. Anthropic audited 141,006 eval runs, suspended those tests on July 23, and notified the affected parties.

The lesson is not "the AI went rogue." The sandbox failed the way a fence fails: someone left a gate open. Misconfiguration, not malice. Which is exactly why "the classifier will catch it" shouldn't be your only layer. I run my own agents under a house law that nothing ships checked once, and this summer is the best argument for it I didn't have to write myself — the people with the biggest safety budgets on earth just showed you what a single-layer failure looks like.

And the tools are consolidating

SpaceX closed its $60 billion all-stock acquisition of Cursor on August 14 — the same day the default flipped, which nobody planned but I notice anyway. Cursor brought roughly $2.6 billion in annualized revenue into SpaceX's AI division, in the second-largest acquisition of a venture-backed company ever.

If Cursor is your daily editor, your workflow now rides on Musk's roadmap. That's not a reason to panic. It is a reason to ask how portable your setup is. Instruction files, skills and subagents, plain markdown — those travel between tools. An IDE's magic doesn't.

One more data point for the pile: Google shipped Gemini 3.7 Flash on August 13 at half its predecessor's launch price. The cost of running agents keeps falling, which means more of them, sooner, with more autonomy by default. This whole month is one arrow pointing the same direction.

What I actually do about it

I run a multi-agent Claude Code setup for my products business, and the permission gates on mine are ones I picked on purpose, agent by agent. The researcher can fetch the web freely; the one that touches money can't move without me. That map didn't come from a default. It came from deciding, per agent, what a mistake would cost.

That's the whole game right now: autonomy is a dial you set, not a fact you inherit. Defaults are for people who haven't decided yet. If you want the long version of how I structure those decisions, the pillar guide is Claude Code Multi-Agent Setup.

FAQ

Does auto mode mean Claude Code can do anything it wants?
No. Every action still passes through the safety classifier before it runs, and you can switch to a stricter permission mode any time. What changed is the starting point: autonomy used to be something you turned on, and now it's something you turn off.

How do I check which permission mode I'm in?
Claude Code's docs keep a live page on permission modes and how to set them. Check it against your own setup rather than trusting a screenshot from a blog post — the exact controls have been changing, and I'd rather send you to the source than describe a menu that moved.

Did Claude "go rogue" in the sandbox-escape incidents?
No. The disclosure describes misconfigured test environments during security evaluations. The models reached the real internet because gates were left open, not because they decided to break out. The lesson is about containment layers, not model intent.

I use Cursor. Do I need to switch?
Not necessarily. But audit your portability now, while it's a calm question instead of an urgent one. If your instructions, skills, and workflows live in plain files, you can move whenever you want — which usually means you won't have to.

Try it yourself

Before your next Claude Code session, check which permission mode you're actually in and decide it on purpose. Keep auto mode if it fits the work. Just make it your choice, not the default's.
