Small party vs. mega-roster: why 10 agents beat 50

2026-07-26 · echov4ult

Giant agent collections demo beautifully. Then you run one on a real project and watch your token budget evaporate into introductions.

There are wildly popular repositories offering 50+ ready-made agents for Claude Code — a specialist for everything, stars in the tens of thousands. We built Full Party with ten. On game projects, we'd argue ten is closer to the ceiling than the floor. Here's the actual argument, not the vibes.

The token math nobody demos

Every agent you invoke pays a fixed overhead: its system prompt, its share of project context, and the cost of re-establishing what's going on. Invoke five agents on a task that needed two, and the extra three don't just add latency — they add full context loads that produce commentary, not verdicts. On a real project with a real budget, a mega-roster turns into a token bonfire with a personality.

The authority problem

An agent's opinion matters only if its verdict is load-bearing — if a "no" from QA actually stops the merge. With 50 agents, verdicts overlap: three roles all sort-of own performance, two sort-of own UX, and when everyone owns something, a rejection is just a comment with formatting. Authority requires scarcity. Ten agents can each own one question outright; fifty cannot.

The maintenance problem

Agents are prompts, and prompts rot: the platform changes, your project changes, your standards change. A roster you can read end-to-end in one sitting gets maintained. A roster the size of a phone book gets abandoned — you'll use four of the fifty forever and the rest are dead weight you paid context for.

What "small" actually means

Our rule from running this on real game projects: six roles cover a full concept-to-ship loop — direction, design, engineering, review, QA, and an adversarial critic. The remaining four in Full Party (Player Advocate, Narrative Designer, Art Director, Marketing Strategist) add depth when the project calls for it, and stay uninvoked when it doesn't. The kit's Single Specialist mode exists precisely so you can use one agent without waking the other nine.

When a big roster is right

Fairness requires the counter-case: if you're exploring what agents can even do, a big collection is a fine museum — browse it, steal role ideas, learn patterns. The failure is running the museum as your team. Curate down to the roles whose verdicts you'd actually obey, give them authority in writing (the practical guide covers how), and let the rest go.
