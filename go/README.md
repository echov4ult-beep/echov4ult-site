# /go/ — the permanent-link layer

One folder per destination. Post THESE links on durable off-site surfaces
(bios, video descriptions, itch pages, email footers) instead of raw Gumroad
URLs — if a store URL ever changes, edit ONE file here instead of chasing
every old post. On-site buttons keep DIRECT links (no hop). New pack ritual:
add /go/<pack-slug>/ pointing at its Gumroad URL in the same commit as its
site product page. Redirect pages are noindex and NOT in the sitemap.
